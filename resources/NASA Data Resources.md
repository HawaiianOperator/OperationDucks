# NASA Hackathon Data Resources

| Resource | Use |
| --- | --- |
| [NASA FIRMS](https://firms.modaps.eosdis.nasa.gov/) | Active fire data |
| [NASA Giovanni](https://giovanni.gsfc.nasa.gov/giovanni/) | Analyze data without coding |
| [AppEEARS](https://appeears.earthdatacloud.nasa.gov/) | Extract data by area |
| [NASA POWER](https://power.larc.nasa.gov/) | Air temperature, rainfall, and solar radiation |
| [SMAP](https://access.earthdata.nasa.gov/collections/C2830464655-NSIDC_CPRD) | Satellite-derived soil moisture |
| [GPM IMERG](https://gpm.nasa.gov/data/imerg) | Precipitation estimates and rainfall accumulation |
| [Landsat NDVI](https://www.usgs.gov/landsat-missions/landsat-normalized-difference-vegetation-index) | Vegetation greenness and changes in vegetation condition |
| [ECOSTRESS](https://ecostress.jpl.nasa.gov/) | Land surface temperature and plant stress indicators |
| [MODIS](https://cmr.earthdata.nasa.gov/search/site/collections/directory/LPCLOUD/gov.nasa.eosdis) | Historical vegetation indices (MOD13 series) and land surface temperature (MOD11 series) |
| [NASA Open Data Portal](https://data.nasa.gov/) | Browse NASA open data |
| [NASA Worldview](https://worldview.earthdata.nasa.gov/) | Explore satellite imagery |
| [NASA Earthdata](https://www.earthdata.nasa.gov/) | Discover Earth science data |
| [USGS EarthExplorer](https://earthexplorer.usgs.gov/) | Find satellite imagery and other geospatial data |
| [MathWorks MATLAB hackathon resources](https://github.com/mathworks/awesome-matlab-hackathons) | MATLAB resources for hackathons |
