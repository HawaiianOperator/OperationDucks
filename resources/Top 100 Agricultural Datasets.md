# Duck’s top 100 agricultural datasets

Ranked for Duck’s field-selection workflow. The order favors a named crop on a known field across consecutive seasons, followed by independent reference labels, measured harvests, and context for decisions. This is an evidence priority list. Sources use different validation methods, locations, and units, so the ranks do not imply comparable accuracy percentages.

**Connected** means Duck uses the indicated feed now. **Sampled** means a public data read was checked. The other entries are documented candidates. Check publisher terms, years, classes, and overlap before adding a candidate. Distinct regional datasets and product layers are listed separately where each supplies a different observation.

Phase Two uses agricultural evidence for rotation and outcome assessment. The weather and remote-sensing context at the end supports Phase One.
